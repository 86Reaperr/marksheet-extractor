# Marksheet Extractor API – Approach Note

## Objective

The objective of this project is to build an AI-powered API that accepts a marksheet in image or PDF format and returns structured JSON containing extracted information along with confidence scores.

---

## Technology Stack

### Backend

* FastAPI

### LLM

* Google Gemini 2.5 Flash

### Supporting Libraries

* PyMuPDF (PDF processing)
* Pillow (Image handling)
* Python-JOSE (JWT Authentication)
* Pydantic (Schema validation)

### Deployment

* Render

---

## Model Selection Reasoning

Gemini 2.5 Flash was selected because:

* Strong multimodal capabilities for both images and document understanding.
* Fast response times suitable for API-based applications.
* Excellent structured JSON generation.
* Cost-effective compared to larger models.
* Handles diverse marksheet formats without template-specific rules.

This allows the system to generalize across different boards, universities, and document layouts.

---

## Extraction Pipeline

### Step 1: File Validation

The API validates:

* Supported formats:

  * JPG
  * JPEG
  * PNG
  * PDF

* Maximum file size:

  * 10 MB

Invalid files return appropriate error responses.

### Step 2: Preprocessing

For PDF files:

* PyMuPDF converts pages into images.

For image files:

* Pillow loads and prepares images for processing.

### Step 3: LLM-Based Extraction

The processed image is sent to Gemini 2.5 Flash along with a structured extraction prompt.

The prompt instructs Gemini to:

* Extract candidate details
* Extract subject-wise information
* Extract result information
* Return valid JSON only
* Generate confidence values

### Step 4: Structured Output

Gemini returns normalized JSON containing:

* Candidate details
* Subject details
* Result information
* Confidence scores

The API returns the structured JSON response to the client.

---

## Confidence Scoring Methodology

Confidence scores range between:

* 0.0 = Not confident
* 1.0 = Highly confident

Scores are generated by Gemini based on:

### Document Visibility

Fields clearly visible in the marksheet receive higher confidence.

### Context Consistency

Values matching expected document patterns receive higher confidence.

Examples:

* Roll Number
* Registration Number
* Exam Year

### Extraction Certainty

When Gemini can directly identify a value, confidence is high.

When information is unclear, partially visible, or missing, confidence decreases.

Typical ranges:

* 0.90 – 1.00 : Clearly visible
* 0.60 – 0.89 : Moderately certain
* 0.00 – 0.59 : Unclear or unavailable

## Authentication

JWT Authentication is implemented.

Workflow:

1. User requests a token.
2. API generates JWT.
3. Protected endpoints validate the token.
4. Unauthorized requests are rejected.

---

## Error Handling

The API handles:

* Unsupported file types
* Oversized files
* Invalid uploads
* Missing authentication
* Gemini API failures

Meaningful error messages are returned to clients.

---

## Scalability and Concurrency

FastAPI supports asynchronous request handling.

This enables multiple concurrent extraction requests and improves responsiveness under load.

FastAPI's asynchronous architecture allows multiple extraction requests to be processed concurrently without blocking the application, making the API suitable for real-world usage and future scaling.

---

## Conclusion

The solution combines FastAPI, Gemini 2.5 Flash, and document preprocessing techniques to provide a scalable and generalizable marksheet extraction API capable of handling both images and PDFs while returning structured JSON with confidence scores.
